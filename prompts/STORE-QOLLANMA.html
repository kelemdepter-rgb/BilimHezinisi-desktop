تولۇق چۈشەندۈرۈش (ئىنگلىزچە)
Bilim Hezinisi turns your books into a searchable personal library that works without an internet connection.

Built for Uyghur, Arabic, Turkish and English text, it handles right-to-left typography and full-text search inside Arabic-script documents properly — something most general-purpose readers get wrong.

FEATURES
• Import and read PDF, DOCX, DOC, TXT, MD and HTML, or save an article from a web address
• Full-text search across your whole library and inside a single book
• Offline OCR for scanned PDFs and images, with Uyghur-specific correction
• A notebook with highlighting, a format painter and automatic references back to the page
• The Qur'an, offline: the Uthmani Hafs Arabic text with the Uyghur translation, searchable
• Uyghur spell-checking
• Export to PDF and DOCX with correct Uyghur typography
• An optional AI assistant — add your own free Google Gemini API key to ask questions about the book you are reading

Completely free. No advertising, no accounts, no tracking. Your library stays on your computer.

This app contains AI-generated content. The optional AI assistant is powered by Google Gemini and only works after you enter your own API key. AI answers can be wrong — please check important material, especially religious content, against the original sources.

تەكشۈرگۈچىگە ئىزاھات
Bilim Hezinisi is a free offline digital library for Uyghur-language books. No login or account is needed — the reviewer can open the app and use every feature immediately.

The app's display name is in the Uyghur (Arabic) script; the Latin transliteration is "Bilim Hezinisi".

To test the optional AI assistant, a free Google Gemini API key from https://aistudio.google.com must be pasted into Settings -> AI. The app is fully functional without it; all other features (import, search, OCR, notebook, Qur'an, export) work offline.

The app stores all data locally in %USERPROFILE%\JamiyKutupxana. It sends no data to any server operated by the publisher.

رەت قىلىنىش ياكى خاتالىق چىقىش نورمال ئىش. Partner Center قايسى ماددىغا خىلاپ كەلگەنلىكىنى ئېنىق يازىدۇ. قايتا يوللاشنىڭ جازاسى ياكى سان چېكى يوق.

«The name found in the package is not one of your reserved app names»

بوغچىڭىزدىكى نام بىلەن بەند قىلغان نام ئوخشىمىغان. تەكشۈرۈڭ: Manage app names دە بىلىم خەزىنىسى بارمۇ؟ بولمىسا 2-باسقۇچنىڭ «ب» قىسمىنى قايتا قىلىڭ. بار بولسا، Claude Code غا package.json دىكى build.appx.displayName نى تەكشۈرتۈپ، Partner Center دىكى بىلەن ھەرپمۇھەرپ سېلىشتۇرتۇڭ.

«Package publisher name ... doesn't match»

Package/Identity/Publisher قۇرى خاتا كۆچۈرۈلگەن. CN= قىسمىنى قوشۇپ، پۈتۈن قۇرنى قايتا كۆچۈرۈڭ. بوشلۇق چۈشۈپ قالماسلىقىغا دىققەت قىلىڭ.

دېتال نامى ??? ياكى قۇتىچە بولۇپ كۆرۈنسە

ئۇيغۇرچە نام بوغچىغا خاتا كودلىنىپ يېزىلغان. Claude Code غا package.json نىڭ UTF-8 ھالەتتە ساقلانغانلىقىنى، BOM يوقلۇقىنى تەكشۈرتۈڭ، ئاندىن قايتا ياساتقۇزۇڭ.

«Privacy policy URL is not accessible»

ئۇلانما ئېچىلمايۋاتىدۇ. repo ئاشكارىمۇ؟ ئۇلانمىدا main دەپ يېزىلغانمۇ (master ئەمەس)؟ برائۇزېردا ئۆزىڭىز سىناپ بېقىڭ.

«Unsupported language» ياكى بوغچا تارقىتىلمىسا

تىل كودى مەسىلىسى. languages چوقۇم ["ug-arab", "en-US"] بولۇشى كېرەك — يالغۇز "ug" Microsoft نىڭ قوللايدىغان تىزىملىكىدە يوق. بۇ ئاللىبۇرۇن تۈزىتىلگەن، لېكىن خاتالىق چىقسا شۇنى تەكشۈرۈڭ.
