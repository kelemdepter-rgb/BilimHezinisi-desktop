# بىلىم خەزىنىسى — ھەقسىز API نى ئىشەنچلىك ئىشلىتىش يولى (2026-يىل 6-ئاي)

> ⚠️ **ئەسكەرتىش:** بۇ ھۆججەت — 2026-يىل 6-ئايدىكى ئەھۋالنىڭ خاتىرىسى. ئىچىدىكى ھەقسىز (free) دەرىجە چەكلىمىلىرى ۋە مودېل ئاتلىرى ۋاقىت ئۆتۈشى بىلەن ئۆزگىرىدۇ؛ ئىشلىتىشتىن بۇرۇن تەمىنلىگۈچىنىڭ رەسمىي ھۆججىتىدىن دەلىللەڭ.

> مەقسەت: «بۇ مودېل بەك ئالدىراش» دېگەن خاتالىقنى ئەڭ ئاز چۈشۈرۈش ۋە Gemini Flash نى توختىماي ئىشلىتىشنىڭ ئەمەلىي چارىسى. ھەممىسى **ھەقسىز (free)** API لارغا ئاساسلانغان.

---

## 1. مەسىلىنىڭ ئاساسى: «بۇ مودېل بەك ئالدىراش» نېمە؟

بۇ خاتالىقنىڭ ئىككى خىل سەۋەبى بار، ئىككىسىنى پەرقلەندۈرۈش ناھايىتى مۇھىم:

| خاتالىق | مەنىسى | سەۋەبى | ھەل قىلىش يولى |
|---|---|---|---|
| **503** «model is overloaded» | گوگلنىڭ مۇلازىمېتىرى تولۇپ كەتكەن | **سىزنىڭ چېكىڭىزگە مۇناسىۋەتسىز** — ھەممە ئىشلەتكۈچىگە (ھەتتا پۇل تۆلىگەنلەرگىمۇ) چۈشىدۇ | قايتا سىناش (retry) + باشقا مودېل/تەمىنلىگۈچىگە ئۆتۈش |
| **429** «quota exceeded» | سىزنىڭ چېكىڭىز توشتى | بىر مىنۇت/بىر كۈنلۈك سوئال سانى ئېشىپ كەتتى (RPM/RPD) | ئاچقۇچنى ئالماشتۇرۇش، ئىشلەتكۈچى بويىچە ئاچقۇچ، سوئالنى ئازايتىش |

**مۇھىم ھەقىقەت:** 503 نى پۈتۈنلەي يوقاتقىلى بولمايدۇ، چۈنكى ئۇ گوگلنىڭ سېرۋېرىدىكى ئەھۋال. بىراق **توغرا قۇرۇلما** بىلەن ئىشلەتكۈچى ئۇنى دېگۈدەك ھېس قىلمايدىغان قىلغىلى بولىدۇ. ئاچقۇچ — «زاپاس زەنجىرى» (fallback chain).

---

## 2. ئاساسلىق چارە: «زاپاس زەنجىرى» + قايتا سىناش

تۆت قاتلاملىق قوغداش:

1. **قايتا سىناش (Retry + backoff):** 503/429 كەلسە، بىردىن ئەمەس، 2 سېكۇنت → 4 سېكۇنت → 8 سېكۇنت كۈتۈپ قايتا سىناش (ئۈستىگە سەل تاسادىپىي «jitter» قوشۇلىدۇ). كۆپىنچە 503 مۇشۇنىڭ بىلەنلا ھەل بولىدۇ.
2. **Gemini ئىچىدىكى زاپاس:** `gemini-3-flash` ئالدىراش بولسا، ئاپتوماتىك `gemini-3.1-flash-lite` غا ئۆتۈش (ئۇنىڭ چېكى تېخىمۇ يۇقىرى، 15 RPM، ئادەттە سەل بوش).
3. **باشقا تەمىنلىگۈчىگە ئۆتۈش:** Gemini پۈتۈنلەي جاۋاب بەرمىسە، Groq ياكى Cerebras غا ئۆتۈش (تۆۋەندىكى جەدۋەلگە قاراڭ).
4. **كەش (Cache):** ئوخشاش سوئالغا قايتا API چاقىرماي، ساقلانغان جاۋابنى ئىشلىتىش. بۇ چەكنى ئەڭ كۆپ تېجەيدۇ.

> ئەسكەرتىش: ئىسىمدا «Gemini 3.5 Flash» يوق. 2026-يىل 6-ئايدا ھەقسىز قاتلامدىكى Flash مودېللىرى: **Gemini 3 Flash** ۋە **Gemini 3.1 Flash-Lite**. (Pro مودېللىرى ئەمدى پۇللۇق.)

| تەمىنلىگۈچى | ياخشى ھەقسىز مودېل | RPM | كۈنلۈك چەك | تېزلىك | كارتا | ئۇيغۇرچىغا | ئىزاھات |
|---|---|---|---|---|---|---|---|
| **Gemini 3 Flash** | `gemini-3-flash` | 10 | ~1500/كۈн | ئوتتۇرا | ❌ | ⭐⭐⭐⭐⭐ | **ئاساسلىق** — ئۇيغۇرچىغا ئەڭ ياخشى |
| **Gemini 3.1 Flash-Lite** | `gemini-3.1-flash-lite` | 15 | يۇقىرى | تېز | ❌ | ⭐⭐⭐⭐ | Gemini ئىچىدىكى زاپاس |
| **Groq** | `llama-3.3-70b-versatile` | 30 | 1000/كۈن (8B مودېل: 14,400) | بەك تېز (~320 token/s) | ❌ | ⭐⭐⭐ | ئەڭ تېز زاپاس؛ كارتا كەرەكмەس |
| **Cerebras** | `llama-3.3-70b` | 30 | **1,000,000 token/كۈن** | ئەڭ تېز (2000+ token/s) | ❌ | ⭐⭐⭐ | token كۆپ، بىراق context 8192 token بىلەن چەكلىك |
| **OpenRouter** | كۆپ `:free` مودېل | 20 | 50/كۈن (credit يوق) ياكى 1000/كۈن ($10 credit) | ھەرخىل | ❌ | ⭐⭐⭐ | بىرلا ئاچقۇچ بىلەن ~30 مودېل |
| **Mistral** | `mistral-large`, `codestral` | — | ~1 مىليارد token/ئاي | ئوتتۇرا | ❌ | ⭐⭐⭐ | token بەك كۆپ، بىراق مەلۇماتىڭىز مەشىققا ئىشلىتىلىدۇ |
| **GitHub Models** | GPT / Llama قاتارلىق | چەكلىك | development چېكى ئىچىدە | ئوتتۇرا | ❌ (GitHub ھésabi) | ⭐⭐⭐ | سىناق ئۈчۈн ياخشى |

**دىققەت:** گوگل ھەقسىز چەكنى ئالدىن ئۇقتۇرماي ئۆزگەرتىدۇ (2025-يىل 12-ئايدا 50–80% كېمەيتكەن). شۇڭا بىرلا تەمىنلىگۈچىگە تايىنىش خەتەرلىك — زاپاس زەنجىرى زۆرۈر.

**ئۇيغۇرچە سۈپىتى توغرىسىدا:** بۇلارنىڭ ئىچىدە ئۇيغۇرچىنى ئەڭ ياخشى بىلىدىغىنى Gemini. Llama/Mistral نىڭ ئۇيغۇرچىسى سەل ئاجىز، ئەмма ئىشلەيدۇ. شۇڭا Gemini نى ئاساسلىق قىلىپ، باشقىلارنى پەقەت «جاۋابسىز قېلىشتىن ياخشى» دېگەن زاپاس سۈپىتىدە ئىشلىتىڭ.

## 4. سىزنىڭ دېتالىڭىزغا ئەڭ مۇھىم نۇقتا: ئاچقۇچ قانداق تارقىتىلىدۇ؟

بۇ بەلكىم سىزنىڭ ئەڭ چوڭ مەسىلىڭىز. ئەگەر دېتالغا **بىرلا ھەقسىز ئاچقۇچ** يوشۇرۇلغان بولسا، **پۈتۈن ئىشلەتكۈچى شۇ بىرلا چەكنى ئورتاقلىشىدۇ** — 10 RPM / 1500 سوئال بىر كۈندە بىرقانچە ئادەم ئىشلەتسىلا توشۇپ كېتىدۇ. ئۇ چاغدا «بەك ئالدىراش» (ئەمەلىيەتتە 429) دائىم چىقىدۇ.

ئىككى يول:

- **(A) ھەربىر ئىشلەتكۈچى ئۆز ئاچقۇچىنى كىرگۈزىدۇ** (تەۋسىيە): ھەركىم ئۆزىنىڭ ھەقسىز 1500/كۈن چېكىگە ئىگە بولىدۇ. چەك مەسىلىسى يىلتىزىدىن ھەل بولىدۇ. دېتالغا «API ئاچقۇچىڭىزنى كىرگۈزۈڭ» دېگەن بىر سۆزلىشىش رامكىسى قوشۇلىدۇ + ئاچقۇچنى قانداق ئېلىشنى كۆرسىتىدىغان قىسقا يېتەكچى.
- **(B) ئۆز سېرۋېرىڭىز (proxy) ئارقىلىق ئۆتكۈزۈش:** ئاچقۇچ يوشۇرۇن قالىدۇ، بىراق پۈتۈن چەكنى سىز كۆتۈرىسىز — ئىشلەتكۈچى كۆپەيسە يەنە توشىدۇ. بۇ يولدا ئاچقۇچ ئالماشتۇرۇش (key rotation) + زاپاس زەنجىرى تېخىمۇ زۆرۈر.

ئەگەر دېتال كۆп كىشىگە تارقىتىلغان بولسا، **(A) نى تاللاڭ** — ھەقسىز مودېل ئۈчۈن بۇ ئەڭ توغرا قۇرۇلما.

## 5. تەييار كود ئۈلگىسى (Node.js / Electron, OpenAI-قا ماس)

Gemini، Groq، Cerebras، OpenRouter ھەممىسى **OpenAI-غا ماس (compatible)** ئۇچ نۇقتىنى قوللايدۇ، شۇڭا بىرلا ئۇسۇل بىلەن ھەммىسىنى چاقىرغىلى بولىدۇ:

```js
// providers.js — كۆп تەمىنلىگۈчىلىك زاپاس زەنجىرى
const PROVIDERS = [
  { name: "gemini-flash",      baseURL: "https://generativelanguage.googleapis.com/v1beta/openai", apiKey: process.env.GEMINI_API_KEY,   model: "gemini-3-flash" },        // ئاساسلىق
  { name: "gemini-flash-lite", baseURL: "https://generativelanguage.googleapis.com/v1beta/openai", apiKey: process.env.GEMINI_API_KEY,   model: "gemini-3.1-flash-lite" }, // Gemini ئىچىدىكى زاپاس
  { name: "groq",              baseURL: "https://api.groq.com/openai/v1",                          apiKey: process.env.GROQ_API_KEY,     model: "llama-3.3-70b-versatile" },
  { name: "cerebras",          baseURL: "https://api.cerebras.ai/v1",                              apiKey: process.env.CEREBRAS_API_KEY, model: "llama-3.3-70b" },
];

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

async function callOne(p, messages, timeoutMs = 30000) {
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), timeoutMs);
  try {
    const res = await fetch(`${p.baseURL}/chat/completions`, {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${p.apiKey}` },
      body: JSON.stringify({ model: p.model, messages }),
      signal: ctrl.signal,
    });
    if (!res.ok) { const e = new Error(`${p.name} HTTP ${res.status}`); e.status = res.status; throw e; }
    const data = await res.json();
    return data.choices[0].message.content;
  } finally { clearTimeout(timer); }
}

// 503/429/تور خاتالىقىدا exponential backoff + jitter بىلەن قايتا سىناش
async function callWithRetry(p, messages, retries = 2) {
  for (let attempt = 0; ; attempt++) {
    try { return await callOne(p, messages); }
    catch (e) {
      const retriable = [429, 500, 502, 503, 504].includes(e.status) || e.name === "AbortError";
      if (!retriable || attempt >= retries) throw e;
      await sleep(Math.min(2000 * 2 ** attempt, 8000) + Math.random() * 1000); // 2s→4s→8s + jitter
    }
  }
}

// زاپاس زەنجىرى: بىرى مەغلۇپ بولسا كېيىنكىسىگە ئۆتىدۇ
export async function chat(messages) {
  let lastErr;
  for (const p of PROVIDERS) {
    if (!p.apiKey) continue;
    try { return { text: await callWithRetry(p, messages), provider: p.name }; }
    catch (e) { lastErr = e; console.warn(`[zapas] ${p.name} mەغلۇپ: ${e.message}`); }
  }
  throw new Error(`ھەممە تەمىنلىگۈچى مەغلۇپ: ${lastErr?.message}`);
}
```

ئىشلىتىش:
```js
const { text, provider } = await chat([{ role: "user", content: "سالام" }]);
console.log(provider, text); // قايسى تەمىنلىگۈچى جاۋاب بەرگەنلىكىنى كۆرسىتىدۇ
```

## 6. API ئاچقۇچ ئالماشتۇرۇش (key rotation) — پايدىسى ۋە ئاگاھلاندۇرۇش

- **429 (كۈنلۈك چەك) غا پايدىسى بار:** بىرقانچە ھەقسىز Google ھېسابى ئاچقۇچىنى نۆۋەت بىلەن ئالماشتۇرسىڭىز، كۈنلۈك ئومۇمىي چەك كۆپىيىدۇ.
- **503 (overload) غا پايدىسى يوق:** ئۇ گوگلنىڭ سېرۋېرىدىكى ئەھۋال، ئاچقۇچ ئالماشتۇرۇش ياردەم بەرمەيدۇ.
- **ئاگاھلاندۇرۇش:** بىر ئادەمنىڭ نۇرغۇن ھېساب ئېچىپ ئاچقۇچ توپلىشى گوگلنىڭ خىزمەت كېلىشىمىگە (ToS) خىلاپ بولۇشى مۇмكىن، ھésab چەكلىنىش خەۋپى بار. ئەڭ ساغلام يول — يۇقىرىدىكى **4-(A): ھەربىر ئىشلەتكۈچى ئۆز ئاچقۇچىنى ئىشلىتىش**. (Groq نىڭ چېكى ھésab/تەشكىلات بويىچە، شۇڭا بىر ئادەمنىڭ كۆп ئاچقۇچى ياردەм بەرمەيدۇ.)

## 7. قىسقىچە يەكۈن (نېمىدىن باشلاش)

1. **بۈگۈن:** كودقا **retry + backoff** ۋە **Gemini 3 Flash → 3.1 Flash-Lite** زاپىسىنى قوشۇڭ. بۇ ئۆزىلا «بەك ئالدىراش» خاتالىقىنىڭ كۆپىنچىسىنى يوقىتىدۇ.
2. **ئاندىن:** Groq ۋە Cerebras نى ھەقسىز تىزىملىتىپ، يۇقىرىدىكى زاپاس زەنجىرىگە قوشۇڭ (كارتا كەرەكمەس).
3. **دېتال كۆپ كىشىگە بولسا:** ئىشلەتكۈچىنىڭ ئۆز API ئاچقۇچىنى كىرگۈزۈشىنى قوشۇڭ — چەك مەسىلىسى يىلتىزىدىن ھەل بولىدۇ.
4. **ئۈنۈمنى ئاشۇرۇش:** ئوخشاش سوئاللارنى كەشلەڭ.

> سۈپەت ئۈчۈن Gemini ئاساسلىق بولۇپ تۇرسۇن؛ Groq/Cerebras پەقەт Gemini جاۋاب بەرمىگەندە ئىشقا چۈشسۇن. شۇنداق قىلسىڭىز ئىشلەتكۈچى ھەمىشە جاۋاب ئالىدۇ، كۆپىنچە ۋاقىتتا Gemini دىن.
