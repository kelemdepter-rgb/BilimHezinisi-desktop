# claude design بىلەن دېتالنى قايتا لايىھەلەش — قەدەممۇ قەدەم يوليورۇق

بۇ خىزمەت **ئىككى باسقۇچ**تىن تۈزۈلىدۇ. بۇلارنى ئارىلاشتۇرۇۋەتمەسلىك ئىنتايىن مۇھىم —
چۈنكى خەتلەر ۋە ئىقتىدارلارنىڭ بۇزۇلماسلىقىنىڭ سىرى دەل مۇشۇ ئايرىمدا:

1. **لايىھە باسقۇچى** — claude design پەقەت دېتالنىڭ **كۆرۈنۈشى (دىزاينى)** نى ياسايدۇ
   (بىر HTML «ئۈلگە/preview»). بۇ باسقۇچتا ئەسلى كودقا **زادى تەگمەيمىز**.
2. **سىڭدۈرۈش باسقۇچى** — شۇ بېكىتىلگەن كۆرۈنۈشنى ئەسلى دېتالغا **بىخەتەر** كىرگۈزىمىز.
   بۇ باسقۇچتا پەقەت CSS (رەڭ، شەكىل، ئارىلىق) ئۆزگىرىدۇ؛ كۇنۇپكا، خەت ۋە ئىقتىدارلار دەخلىسىز قالىدۇ.

مەن سىزگە بۇيرۇقنى تەييار يېزىپ قويدۇم:
**`prompts/design-prompt-full-ui-redesign.md`** (ئىنگلىزچە — claude design ئەڭ ياخشى چۈشىنىدۇ).

---

## باسقۇچ 1 — تەييارلىق

ئالدىڭىزغا ئىككى نەرسە تەييارلاپ قويۇڭ:

- بۇيرۇق ھۆججىتى: `prompts/design-prompt-full-ui-redesign.md` (مەزمۇنىنى ھازىر كۆچۈرۈشكە تەييار قىلىڭ).
- **8 پارچە كۆرۈنمە يۈزى رەسىمى** (7 يورۇق + 1 قاراڭغۇ). قاراڭغۇ ھالەت رەسىمىنى چوقۇم قوشۇڭ —
  شۇنداق بولغاندا claude design Day ۋە Night ئىككىسىنى تەڭ كۆرەلەيدۇ.

## باسقۇچ 2 — claude design نى ئېچىش ۋە بۇيرۇقنى بېرىش

1. Claude (claude.ai ياكى Claude دېتالى) دا **يېڭى سۆھبەت** ئېچىڭ.
2. «قايسى تۈرنى تاللاش» دېگەن مەسىلىگە كەلسەك — **مۇھىم ئەمەس**. ئالاھىدە بىر «تۈر» تاللىشىڭىزنىڭ
   ھاجىتى يوق؛ **ئادەتتىكى سۆھبەت**نىلا تاللاڭ. چۈنكى بۇيرۇقنىڭ ئۆزى claude design غا «نېمە ياسايسەن،
   قانداق چىقىرىپ بېرىسەن» دېگەننى تولۇق ئېيتىپ بەرگەن. (Claude نەتىجىنى ئۆزلۈكىدىن **interactive HTML
   preview / artifact** قىلىپ چىقىرىدۇ — يەنى سىز كۆرەلەيدىغان، چېكىپ سىنىيالايدىغان كۆرۈنۈش.)
3. بۇيرۇق ھۆججىتىنىڭ **پۈتۈن مەزمۇنىنى كۆچۈرۈپ** سۆھبەتكە چاپلاڭ.
4. **8 رەسىمنى قوشۇڭ** (سۆھبەتكە سۆرەپ تاشلاڭ ياكى رەسىم قوشۇش كۇنۇپكىسىدىن).
5. ئەۋەتىڭ.

## باسقۇچ 3 — كۆرۈنۈشنى كۆرۈش ۋە تۈزىتىش

1. claude design سىزگە بىر HTML **ئۈلگە (preview)** چىقىرىپ بېرىدۇ. ئۇنى ئېچىپ كۆرۈڭ.
2. ئىچىدىكى **Day / Night** كۇنۇپكىسىنى بېسىپ ئىككى ھالەتنى تەڭ سىناڭ.
3. بىر يېرى كۆڭلىڭىزگە ياقمىسا، شۇنى ئېيتىپ قايتا ياسىتىڭ. مەسىلەن:
   *«كىتاب كارتىلىرىنى تېخىمۇ چوڭ قىل»*، *«ئالتۇن رەڭنى ئازراق ئىشلەت»*، *«قاراڭغۇ ھالەت تېخىمۇ
   قارا بولسۇن»* دېگەندەك. كۆڭلىڭىزدىكىدەك بولغۇچە تەكرارلىۋېرىڭ — بۇ باسقۇچتا ھېچ نەرسە بۇزۇلمايدۇ.

## باسقۇچ 4 — نەتىجىنى ساقلاش

كۆرۈنۈش ياققاندىن كېيىن، claude design چىقارغان **HTML ھۆججىتىنى** (ۋە بەرگەن CSS نى) ساقلاپ ياكى
كۆچۈرۈپ ئېلىڭ. (ئەگەر مۇشۇ يەردە، مەن بىلەن ئىشلىسىڭىز، پەقەت «تامام بولدى» دېسىڭىزلا كۇپايە.)

## باسقۇچ 5 — دېتالغا بىخەتەر سىڭدۈرۈش ⭐ (ئەڭ مۇھىم باسقۇچ)

بۇ يەردە خەت ۋە ئىقتىدارلارنىڭ بۇزۇلماسلىقى ھەل قىلىنىدۇ. **تەۋسىيە قىلىنغان، ئەڭ بىخەتەر يول**:

> شۇ نەتىجىنى **ماڭا (مۇشۇ يەرگە، Cowork غا) قايتۇرۇپ بېرىڭ** — «claude design مۇنداق لايىھە بەردى،
> ئەمدى دېتالغا سىڭدۈرۈپ بەر» دەڭ. مەن:
> 1. سىزنىڭ ئەسلى `src/index.html`، `src/quran.css`، `src/notes.css` ئىڭىزنى ئوقۇيمەن؛
> 2. پەقەت **كۆرۈنۈش قاتلىمى**نىلا يېڭىلايمەن — رەڭ ئۆزگەرگۈچىلىرى (CSS variables) ۋە بۆلەك ئۇسلۇبلىرى؛
> 3. ھەربىر `id`، `onclick`، `data-*`، ئۇيغۇرچە خەت، CSP (`connect-src 'self'`) ۋە CRLF نى **ساقلاپ قالىمەن**؛
> 4. ئاندىن `node --check` ۋە `npm start` بىلەن سىناپ، ھېچ ئىقتىدارنىڭ بۇزۇلمىغانلىقىنى جەزملەشتۈرىمەن.

**نېمە ئۈچۈن بۇ يول بىخەتەر:** بىز پەقەت CSS (رەڭ ۋە شەكىل) نى ئالماشتۇرىمىز. دېتالنىڭ HTML قۇرۇلمىسى،
كۇنۇپكا باغلىنىشلىرى (`onclick`) ۋە JS ئىقتىدارلىرى **ئەينەن قالىدۇ**. شۇڭا «خەتلىرى ياكى ئىقتىدارلىرى
بۇزۇلۇپ كېتەمدۇ» دېگەن ئەنسىزلىكنىڭ ھاجىتى يوق.

(باشقا يول — **Claude Code** ئارقىلىق: ئەگەر سىز Claude Code ئىشلەتمەكچى بولسىڭىز، مەن سىزگە ئايرىم
«handoff» بۇيرۇقى يېزىپ بېرەلەيمەن. سىزنىڭ `prompts/prompt11-ui-redesign.md` ئىڭىز دەل شۇ ئۇسۇلدا
ئىشلەنگەن. ئەمما يۇقىرىقى، مەن بىلەن قىلىدىغان يول تېخىمۇ ئاددىي ۋە بىخەتەر.)

## باسقۇچ 6 — تەكشۈرۈش ۋە يېڭى نۇسخا چىقىرىش

1. دېتالنى ئېچىپ، Day/Night نى ئالماشتۇرۇپ، ھەربىر بەت ۋە كۇنۇپكىنى بېسىپ سىناڭ.
2. ھەممىسى جايىدا بولسا، يېڭى **exe / قاچىلىغۇچ (installer)** نى ياسايمىز (`npm run dist-win`).

## بۇيرۇق claude design غا نېمە دەيدۇ (قىسقىچە)

- بۇ دېتالنىڭ **مەزمۇنى ۋە ئىقتىدارىنى** ئاساس قىلىپ، **ئەڭ سۈپەتلىك، كەسپىي** كۆرۈنۈش لايىھەلىسۇن؛
  قايسى يەرنى قانداق لايىھەلەشنى **ئۆزى بەلگىلىسۇن** (ئەركىن لايىھە).
- **بارلىق ئۇيغۇرچە خەت، بارلىق ئىقتىدار ۋە كۇنۇپكىلار ئەينەن ساقلانسۇن** — ھېچنېمە ئۆچۈرۈلمىسۇن، ئىسمى ئۆزگەرتىلمىسۇن.
- **RTL (ئوڭدىن سولغا)** مەجبۇرىي؛ **تورسىز** (تاشقى font/CDN يوق)؛ **Day + Night** ئىككىسى تەڭ مۇكەممەل.
- مەۋجۇت **رەڭ ئۆزگەرگۈچىلىرى (CSS variables)** نى شۇ پېتى ئىشلەتسۇن — شۇنداقتا نەتىجە دېتالغا توغرا چۈشىدۇ.
- نەتىجىنى **بىر HTML ئۈلگە (preview) + CSS** قىلىپ تاپشۇرسۇن.

> قىسقىسى: **لايىھەنى claude design ئەركىن ياسايدۇ؛ سىڭدۈرۈشنى بىز بىخەتەر، سىناپ تۇرۇپ قىلىمىز.**
> ھەرقانداق باسقۇچتا تورىسىپ قالسىڭىز، ماڭا دەڭ — داۋاملاشتۇرۇپ بېرىمەن.
