تور بەت قوشۇش

ماقالە ئادرېسىنى كىرگۈزسىڭىز، بەتنىڭ ئاساسىي مەزمۇنى (ئىزدەش بالدىقى، ئۇلانما، ئېلانلارسىز) ساپ تېكىست ھالىتىدە كىتاب بولۇپ ساقلىنىدۇ:

بىلىم خەزىنىسى تور بېتىدىن چۈشۈرۈش

يانمۇيان ئوقۇش

تاللىغان كىتاب سول تەرەپتە ئېچىلىدۇ. خەتكۈچ، ئىزاھات، سۈنئىي ئىدراك ۋە ئوقۇش ئورنى ئوڭ تەرەپتىكى كىتابتا قالىدۇ.

تەڭشەكلەر

سۈنئىي ئىدراك (Gemini)

قوزغاتسىڭىز ئوقۇغۇچتا AI كۇنۇپكىسى كۆرۈنىدۇ

ھەقسىز API ئاچقۇچىنى aistudio.google.com تور بېتىنىڭ «Get API key» بۆلىكىدىن ھاسىل قىلىپ كۆچۈرۈپ، بۇ يەرگە چاپلاڭ. (كونا ئاچقۇچلار «AIza» بىلەن، يېڭىلىرى «AQ.» بىلەن باشلىنىدۇ — ئىككىلىسى بولىدۇ)

ئەگەر يۇقىرىدىكى Gemini API ئاچقۇچى ئالدىراش، ھەققى توشقان ياكى ئىناۋەتسىز بولۇپ قالسا، زاپاس ئاچقۇچقا ئاپتوماتىك ئالمىشىدۇ — سىز ھېچنېمە قىلمايسىز، تاللىغان مودېلىڭىز ئۆزگەرمەيدۇ، پەقەت ئاچقۇچلا ئالمىشىدۇ. ھەر بىر زاپاس ئاچقۇچنى ھاسىل قىلغاندا چوقۇم «Choose an imported project» دىن ئوخشىمىغان «project» بەلگىلەپ ھاسىل قىلىڭ. شۇنداق بولغاندا، ھەربىر Gemini API مۇستەقىل ھەققى بولىدۇ (ھەقسىز ھەق ھەر بىر project غا ئايرىم ھېسابلىنىدۇ).

«ھەقسىز» مودېللار Google نىڭ ھەقسىز ھەققى بىلەن ئىشلەيدۇ. «پۇللۇق» مودېل ئۈچۈن Google ھېساباتىڭىزدا billing ئوچۇق بولۇشى شەرت. باھالار ئۆزگىرىپ تۇرىدۇ — Google نىڭ باھا بېتى ↗

زاپاسلاش ۋە ئەسلىگە كەلتۈرۈش

كۇتۇپخانا (كىتابلار، خەتكۈچلەر، خاتىرىلەر) ھەپتىدە بىر قېتىم ئۆزلۈكىدىن زاپاسلىنىدۇ؛ ئەڭ يېڭى 3 زاپاس ساقلىنىدۇ. زاپاسنى USB ياكى باشقا دىسكىغا كۆچۈرۈپ قويسىڭىز تېخىمۇ بىخەتەر.

كىتابلارنى تەكشۈرۈش

بەزى Word ھۆججەتلىرى ئۇيغۇرچىنى ھەرپ ئەمەس، «ھەرپ شەكلى» قىلىپ ساقلايدۇ: بەتتە توغرا كۆرۈنىدۇ، ئەمما ئىزدەشتە تېپىلمايدۇ. تەكشۈرۈش ھېچنېمىنى ئۆزگەرتمەيدۇ؛ ئوڭشاشتىن بۇرۇن كۇتۇپخانا زاپاسلىنىدۇ.

ئۆزىڭىزگە تەۋە رەقەملىك كۇتۇپخانا

نەچچە يۈزلىگەن كىتابلارنى ئۆزىگە سىغدۇرالايدىغان، پۈتۈنلەي ھەقسىز، سۈنئىي ئىدراكلىق كۇتۇپخانا دېتالى.

ئۇيغۇرچە، ئەرەبچە، تۈركچە ۋە ئىنگلىزچە PDF، TXT، DOCX، DOC، MD، HTML قاتارلىق ئاساسلىق ھۆججەت فورماتلىرىنى تولۇق قوللايدۇ. مەزمۇن بويىچە كىتاب قوشۇش، ئىچىدىن مەزمۇن ئىزدەش، ئوقۇش، كىتاب مەزمۇنىغا قارىتا سۈنئىي ئىدراك ئارقىلىق مەشغۇلات ئېلىپ بېرىش ئىنتايىن قولايلىق لايىھەلەنگەن.

سۈنئىي ئىدراكلىق ئىخچام، تېز ۋە ئەتراپلىق — شەخسىي كۇتۇپخانىڭىز ھەر ۋاقىت يېنىڭىزدا!
